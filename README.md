# 🚀 WordPress + MariaDB + phpMyAdmin avec Docker

## 📌 Description

Ce projet déploie un environnement complet **WordPress** avec :

- 🗄️ MariaDB (base de données)
- 🌐 WordPress
- 🛠️ phpMyAdmin (administration de la base)
- 🐳 Orchestration via Docker Compose
